UNDER THE HOOD

从任务到可审计的运行记录

  1. 解析任务识别行业和受支持的请求，遇到歧义先要求补充信息。
  2. 按预算调用工具在限定调用次数内执行 Python 工具。制造交接可以把风险排序接到巡检和工单草稿。
  3. 检查输出与来源区分历史登记、公开基准与合成数据，保留计算输入和过程。
  4. 移交人工复核优先标出待核事项。可下载完整 JSON，或通过场景链接分享标准回放。
